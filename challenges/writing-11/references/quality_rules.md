# 学术翻译质量细则（术语稳 / 数字实 / 对得齐 / 边界清）

## 1. 术语稳
- **抽取顺序**：给定术语（`case.glossary`/`locked_terms`，索引中为 `supplied_terms`）＞高频缩写（init 的 `term_candidates`）＞领域名词短语（`-tion/-sis/-ity` 结尾）。
- **锁定**：一个 `term` 全篇一个 `target`，含摘要、正文、图注、表注、脚注、附录；图注术语必须与正文一致（常见失分点）。
- **学科歧义**：`resolution` 在成像语境译“分辨率”、在化学语境译“分离度”；`significant` 统计语境译“显著的”，一般语境译“明显的”。选一次写入 `glossary.note`，不要逐段重译。
- **缩写首次出现**：`X-ray diffraction (XRD)` → 「X 射线衍射（XRD）」，后续沿用缩写；原文未展开的缩写不自行展开。
- **不要造词**：无公认译名时写 `术语（原文）` 并列入 `pending_human`。

## 2. 数字实
- **逐字落地**：数值、小数位、范围、年份、样本量、`p` 值、置信区间、温度、浓度、投加量、放大倍率，全部与原文一致。`95% CI: 92–98%` 不写成 `92–98%`，`n = 3` 不写成 `3 次`（可写 `n = 3`）。
- **中文 ↔ 英文量级**：`3.2 万` = `32,000`（不是 `3.2 million`）；`1.5 亿` = `150 million`；`万亿` = `trillion`。换算后的数字必须与原文等值，并在 `note` 记原写法。
- **单位**：不换算、不省略、不改大小写敏感形式（`mg/L`、`mL`、`°C`、`min⁻¹`）；原文 `min−1` 里的 U+2212 负号照抄。
- **统计口径**：`mean ± SD`、`median (IQR)`、`two-tailed`、`95% CI` 等口径短语随数字一并保留。
- **公式与符号**：`k = 0.031 min⁻¹`、`·OH`、`TiO2` 的下标、`R²` 的上标按原文；公式块整体搬运，不改符号。
- 校验由 `preserved_facts.json` 逐条给出 `present_in_target`；为 `false` 的必须补回或写明原因。

## 3. 对得齐
- 一段对一段：`para_id` 不变、段序不变；不改写为“合并成流畅长段”，作者需要逐段对照修改。
- 图表结构：`图 3` → `Figure 3` 编号不变；表题、表注跟随表格位置；脚注用相同标记（`a, b, *`）挂在对应位置。
- 参考文献：条目内容（作者、年份、刊名、卷期页、DOI）逐字保留，只调整体例标点；编号 `[12]` 不变。
- 标题层级：`## 参考文献` 译作 `## References`，层级标记不带进译文正文。

## 4. 边界清（不越界）
- **否定范围**：`The rate did not increase because of salinity` ≠ 「因为盐度速率没有增加」。保持修饰范围，必要时调整语序而非改变逻辑。
- **因果强度**：`suggests / indicates / demonstrates / proves` 依次递增，译作「提示 / 表明 / 证明 / 证实」，不升级也不降级。
- **模糊限制**：`may / might / likely / probably / up to / at least` 必须显化，不能删。
- **条件与前提**：`under UV irradiation, at pH 3` 一类条件短语不得省略。
- **增译**：仅补主语、连接词、量词以合语法；不引入原文没有的机制、比较或结论。
- **省译**：仅限重复虚词与英文冠词；限定词、数量词、引用不省。
- **归属**：`Zhang et al. reported…` 保持“他引”，不写成本研究结论；作者未说的推断不得写入译文。

## 5. 语域与可读性
- 学术语域：避免口语化（`a lot of` → `considerable`）与宣传腔（`novel breakthrough` 类拔高），避免逐字直译的中文长定语堆叠。
- 中文用全角标点，英文用半角；英文数字与单位间保留空格（`12.5 mg/L`）。主被动按目标语言习惯调整，不改变施事受事。

## 6. 何时写入 pending_human（而不是硬译）
1. 术语无公认译名或存在两种并存译法；
2. 原文数字/单位冲突（正文 95%、表中 92%）——保留两者并标注；
3. 指代跨段不明、句子残缺、材料缺页、图像文字无法取读；
4. 需要外部文献才能确定的论断。
每条给出 `item`、`reason`、`locator`，便于作者定点处理。
