# 图型判读手册（reading-02）

按图型给出「先看什么、怎么读、哪里最容易错」。所有规则只用于**判读**；没有依据的量一律
`undetermined`，不写进事实层。

## 1. 折线 / 散点 / 动力学曲线

1. 先定图框：上下左右轴脊是否闭合（本工具输出 `spines_px`；无上/右脊时用轴起点反推）。
2. 刻度：主刻度均布 ≠ 线性；**只有**次级刻度呈递减间距或标签为 10ⁿ 时才判对数。
3. 单位：轴标签括号内逐字抄（`mV`、`kPa`、`µε`），不要跨轴借单位。
4. 系列：色簇 + 图例色块顺序联合判定；同色多系列（不同 marker）时说明无法区分。
5. 读数：每列取中位纵坐标，线宽即 `px_thickness`；曲线交叠处列厚度突增，交叠段标 `undetermined`。
6. 常见错误：把图例色块当成数据点；把网格线当曲线（网格是低饱和灰，工具按饱和度排除）。

## 2. 柱状 / 箱线 / 带误差线

1. 柱高读的是柱顶像素 → 用 y 轴标定换算；柱宽与间距不是数据。
2. 误差线：先读图注确定 SD/SEM/95%CI/range；无图注时只能写「线帽范围」并标 `inferred`。
3. 箱线：须读中位线、箱上下沿（Q1/Q3）、须端（1.5 IQR 或 min/max，依图注）；缺图注则 `undetermined`。
4. 显著性：`*`/`**`/`n.s.` 与括号位置要一起记录（比较的是哪两组）。
5. 常见错误：把误差线当成第二个系列；把 n.s. 写成显著。

## 3. 光谱 / 峰形

1. 横轴常为波数/波长/能量，注意方向（FTIR 常左大右小）。
2. 峰位：局部极小（透过率）或极大（吸收/强度）的像素列 → 标定后给峰位；峰强取相对基线。
3. 峰宽只报「半高宽近似」，不报仪器分辨率；不做物质归属（题面明确不要求仅凭图像定性）。
4. 常见错误：把坐标轴刻度字形的锯齿当峰；把基线漂移当峰。

## 4. 显微 / 照片 / 示意图

1. 无轴框 ⇒ `traceable=false`，只报尺寸、色簇、比例尺候选，不做定量。
2. 比例尺：先读图注/尺上标注长度（µm），再与尺的像素长度换算；无标注则只报像素长度。
3. 计数/粒径：需目视或分割，本工具不自动分割；由 Agent 判读并给 bbox 证据。
4. 常见错误：把比例尺当数据条；用物理直觉改图注单位。

## 5. 多子图 Figure

1. 逐子图建条目：`panel` + `figure_id` + 该子图自己的轴与图例，**禁止跨子图共享图例**。
2. 图注常把 (a)(b)(c) 的条件写在一句里，须把条件绑定到对应 panel。
3. 汇总结论只能写图注/正文明确的比较；跨子图数值不做拼接运算。
4. 未给像素的子图（只在正文出现图注）列 `coverage.missing_images`，不推断其数据。

## 6. 表格

1. 表头逐字保留（含单位行、括号、上下标写法）；不合并、不交换列。
2. 分组表头（跨列）用两行表头 + 说明行处理，不压平。
3. 缺失单元格留空，不填 0；`—`/`N/A`/`n.d.` 原样保留并在 `uncertainties` 说明其含义未给出。
4. 脚注（显著性标记、样本量、条件）单独记录，不并入数据列。

## 7. 异常处置矩阵

| 现象 | 判定 | 动作 |
|-|-|-|
| 无刻度、无图框 | 照片/示意图 | `traceable=false`；报色簇/尺寸；需要量值时进 `pending_human` |
| 图被裁切 | 轴缺一端 | bbox 取可见范围；缺端刻度不补；`uncertainties` 记裁切 |
| 图例缺失 | 色块无名 | 按色簇面积/位置给候选；`readability=inferred` |
| 单位不明 | 轴标签无单位 | `unit=null`；**不得**当作无量纲 |
| 过曝/低对比 | 背景与墨迹不可分 | 降级为目视判读；`degradations` 记录 |
| 曲线重叠 | 列厚度异常 | 交叠区不输出点；给区间与理由 |
| 双纵轴 | 左右刻度不同 | 分 `y` / `y2` 两套标定，禁止混算 |
| 反向轴 | 值随像素同增 | 工具自动校正方向；仍须在 `axes.*.scale` 说明 |
| JPEG/TIFF | 无标准库解码 | 结构分析跳过；Agent 目视读数写 `readings.json` |

## 8. 判读顺序（每次照做）

轴 → 单位 → 图例 → 系列 → 数据点/趋势 → 误差与显著性 → 图注条件 → 结论（附 quote 或 bbox）。
跳步是最常见的失分来源：先下结论再找依据，几乎必然出现「图中无此数」。
