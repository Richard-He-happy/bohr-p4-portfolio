# 判定方法、阈值、排序规则与限制

全部阈值集中在 `scripts/analysis.py` 顶部 `CFG`，可改一处即全局生效。

```python
CFG = dict(z=3.5, zw=2.5, reps=3, cv=30.0, anom=40, brk=0.15, minz=0.02)
```

| 键 | 默认 | 含义 |
|---|---|---|
| `z` | 3.5 | `|robust z| ≥ z` 判 `confirmed_outlier` |
| `zw` | 2.5 | 观察带；`zw ≤ |z| < z` 记为 `watch` |
| `reps` | 3 | 低于该重复数打 `short_reps` 标签 |
| `cv` | 30.0 | 组内 CV(%) 参考上界，判 `hetero` 用 |
| `anom` | 40 | 异常条目上限（按严重度截断） |
| `brk` | 0.15 | 拐点需达到的最小 SSE 降幅 |
| `minz` | 0.02 | 稳健尺度下限（中位数绝对值的 2%），防止尺度塌缩致误报 |

## 1. 稳健统计

- 中枢 `median`，尺度 `1.4826 × MAD`；MAD 塌缩时回退样本标准差；
  再与 `minz × |median|` 取大，避免低噪声数据把微小波动判成异常。
- 偏差 `dev_pct = (value − reference) / |reference| × 100%`。

## 2. 异常判定的三层参照（关键设计）

1. **水平参照优先**：若同表存在数值列充当设计因子（取值数 2–15 且每水平 ≥3 行，如剂量、浓度、时间点），
   参照中枢取**同一水平**的中位数/MAD。这样「随剂量升高」不会被误判为离群点。
2. **无水平参照**：退回整列稳健中枢，此时梯度数据会被标记，需结合 `trend` 段人工判读。
3. **例外**：判定结果为 `short_reps` 标签时，明确写「补齐后 z 可能回落」，不当作真实异常。

另设两类独立判据：

- **跨曲线比较**（`series_outlier`）：按标识列切块（或宽表按数值列）提取每条曲线的峰值、
  面积（梯形积分）、初始斜率，再对这三个特征做稳健 z。用于「哪个试样/通道异常」。
- **文本限度**（`oos_limit`）：当同一行文本单元格写明 `≤ / <= / NMT / 不超过 / 限度 / limit` 的数值时，
  与该行数值列比较。**限度只来自材料，不外部编造**。

## 3. 趋势与拐点

- 自变量：取值集合为严格递增且基本唯一（`|唯一值| ≥ 5` 且 ≤ 0.8×行数+2）的数值列；
  同一自变量的多行重复先**按水平求均值**，再拟合，避免重复数不均带来的斜率偏移。
- 线性拟合给斜率、R²；`R² < 0.1` 记为「无显著趋势」。
- 拐点：对折两段最小二乘，仅在 `SSE 降幅 ≥ brk` 时报告；`sign_flip` 记为「先升后降/先降后升」，
  否则若后段斜率 < 前段 25% 记为「后转平台」。
- 曲线表（存在重复的水平轴标识块）额外给代表曲线的 `k_init`、平台占比、峰后跌落百分比。

## 4. 原因排序

候选原因来自已触发的证据标签，逐条附：机制、支持证据（带 `locator`/`quote`）、可检验性 1–5、
验证动作、成立判据、否定判据。得分：

```
score = min(支持证据条数, 3) × 2 + 可检验性 / 2
```

按 `score` 降序赋 `rank`。设计意图：**证据多的优先，但高可检验性的候选也能靠前**，
因此「先花 10 分钟能排除的」不会被埋在后面。

固定候选表（触发条件 → 原因）：

| 标签 | 候选原因 | 可检验性 |
|---|---|---|
| `magnitude` | 单位换算/数量级录入错误 | 5 |
| `clipping` | 读数封顶、信号饱和 | 5 |
| `batch` | 批次/通道系统偏差 | 4 |
| `short_reps` | 重复数不足导致的伪异常 | 5 |
| `no_control` | 缺对照，难分系统偏差与处理效应 | 4 |
| 有异常且无上述标签 | 单点操作误差 | 3 |
| 无异常 | 未检出离群点（不等于不存在） | 5 |

## 5. 批次/通道绑定

把已确认异常按批次列计数。若**某一水平承担 ≥50% 且 ≥2 个**异常，标 `batch` 标签，
写成「n/N 个确认异常集中在 X」，并进入原因表第一位（附该计数作为证据）与复核表 P1。
这是本 Skill 相对通用统计工具的主要增量：**异常不只被找到，还被绑定到维度**。

## 6. 复核清单生成

- 每个 `outlier`/`oos_limit` 生成 P1「回查原始导出、单位与限度口径」，附目标 `locator` 与工时估计；
- 每个证据标签生成对应动作（补重复、稀释重测、插质控样、补对照），各带成立/否定分支；
- 无任何异常时生成 P2「抽 5 行按原始记录复算」的兜底核对项。

## 7. 适用条件

- 需要有**数值读数**；纯定性记录只能走降级路径。
- 每水平 ≥2 行才启用水平参照；`n < 3` 的组只给出设计缺口提示。
- 拐点需要 ≥8 个水平点；曲线特征需要 ≥6 点/条。
- 单表最多扫描 12 个数值列、24 个 sheet、4000 行；超出截断并记 `counts`。

## 8. 已知限制（写进 `uncertainty`，勿删）

1. 阈值未经方法验证文件校准，只是稳健默认值；正式报告应替换为实验室允差。
2. 分组键与设计因子自动推断，可能与真实分层不符，需人工核对 `groups[].key`。
3. 原因是候选并附否定判据，未做排除实验前不构成因果结论。
4. 图像、图谱、PDF 不做数值读取；表格之外的证据一律登记为缺口。
5. 不联网、不引用文献；材料未给的仪器参数、试剂目录号、限度值一律留空。

## 9. 曲线表与点级异常的协同（重要）

- 当表可拆成曲线（存在递增自变量 + 标识列，或宽表按数值列成序列）时，走**曲线级比较**：
  用每条曲线的峰值/面积/初始斜率做稳健 z，回答「哪个试样/通道异常」。
- 曲线数 <5 时曲线级比较不可靠，脚本会**自动补跑点级判定**（按水平参照的稳健 z），
  避免「只有两条曲线时点异常被漏掉」。
- 自变量为严格递增且唯一（典型曲线）时，允许其作为横轴，因此曲线数据也能给出 R²、
  幅度%、拐点，而不只是初始斜率。
- 宽表按列成序列的路径最多读取 2000 行；超出仅取前 2000 行，超限记在 `counts`。

## 10. 明确不解析的形态

- XLSX 的 `inlineStr` 单元格（极少见）不特殊处理，按空值降级；公式只读缓存值 `<v>`。
- 合并单元格不做语义展开；图表、图片、批注不读。
- PDF/图片只登记为缺口，不提取数值。
