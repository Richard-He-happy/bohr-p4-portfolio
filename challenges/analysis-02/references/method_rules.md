# 方法与口径（analysis-02）

本文件记录 `scripts/statsx.py` 每个统计量的定义、口径、参考实现对照结果与已知边界。评审或使用者可用它复算 `tables/*.csv` 中的任何数字。

## 1. 描述统计口径

| 统计量 | 定义 | 说明 |
|-|-|-|
| `n` | 非缺失观测数 | 每个变量单独计；缺失不插值、不补 0 |
| `mean` | 算术平均 | — |
| `sd` | 样本标准差，分母 `n−1` | 与 R `sd()`、pandas `.std()` 默认一致 |
| `se` | `sd/√n` | — |
| `median`/`q1`/`q3`/`iqr` | 线性插值分位（R type 7） | `h=(n−1)q`，与 numpy 默认一致 |
| `min`/`max`/`range` | 观测极值 | 不剔除异常值 |
| `cv` | `sd/mean` | 仅均值非零时给出 |
| `skew_g1` | 偏差校正 Fisher–Pearson G1（n 分母矩） | 与 `scipy.stats.skew(bias=False)` 一致 |
| `kurt_g2` | 偏差校正超额峰度 G2 | 与 `scipy.stats.kurtosis(bias=False)` 一致 |
| `mean_ci` | `mean ± t(0.975, n−1)·se` | 区间是**均值**的区间，不是个体取值范围 |

## 2. 检验选择树

```
两组比较
├─ 各组 n≥8 且 D'Agostino K² p≥0.05（不拒绝正态）
│  ├─ Levene p≥0.05（方差齐）→ Student t（合并方差，df=n1+n2−2）
│  └─ Levene p<0.05（方差不齐）→ Welch t（Welch–Satterthwaite df）
└─ 任一组 n<8，或正态性被拒且某组 n<30 → Mann–Whitney U（正态近似 + 连续性校正 + 结校正）

三组及以上
├─ 各组满足方差齐性前提且 ANOVA 有效 → 单因素 ANOVA（F, df1=k−1, df2=N−k）
└─ 否则 → Kruskal–Wallis（H，结校正），df=k−1
事后：参照组（n 最大）vs 其余各组，Holm 校正
```

要点：

- 正态性是**前提检查**，不是结论；n<8 无法检验时不假装通过，直接走秩检验。
- 两组都正态但方差不齐时用 Welch 而非 Student，避免 I 类错误膨胀。
- 三组数据不会被塞进两样本 t 检验（这是本题点名的方法误用）。
- 零方差组：t 检验无定义，返回 `decision="insufficient"` 并说明原因，不输出伪造的 p。

## 3. 效应量映射

| 设计 / 检验 | 效应量 | 计算 | 区间 |
|-|-|-|-|
| 两组 t（Student/Welch） | Hedges g | `J·(m1−m2)/s_pooled`，`J=1−3/(4(n1+n2)−9)` | Hedges–Olkin 大样本 SE 线性化，乘 J |
| 两组秩检验 | 秩二列相关 r | `2U/(n1·n2)−1`（方向：group1 高于 group2 为正） | 不给（秩检验无稳定解析 CI），点估计旁明示“CI 不可得” |
| 单因素 ANOVA | eta² | `SS_between/SS_total` | 不给（同理），并同时给出 omega² 供核对 |
| Kruskal–Wallis | epsilon² | `(H−k+1)/(N−k)` | 不给 |
| 均值差 | `m1−m2` | — | t 区间（与所选 t 变体一致） |
| 中位数差 | `med1−med2` | — | 百分位 bootstrap，2000 次，种子固定 |

惯例分级（仅作参照，不作结论）：|g| 0.2/0.5/0.8 为小/中/大。报告里始终给出数值与区间，**不只给“显著”**。

## 4. 多重比较

- 同一结局变量的多组事后比较：Holm（控制族错误率，比 Bonferroni 更有功效）。
- 多个结局变量：另做一次 Holm，写进 `p_adj_outcome` + `adjust_scope`，避免“反复换方法凑显著”。
- 校正后的 p 与未校正 p 同时保留，解释以校正后为准。

## 5. 与 SciPy 的数值对照（本包实测）

用 60/45 例、三组 25 例的固定随机数据逐项比对（`statsx` vs `scipy 1.16.1`）：

## 6. 已知边界与失败案例（避免同类误用）

1. **把缺失当 0**：本包把缺失按单元格计数后做完整案例分析，`cleaning.issues` 里写清每列缺口，绝不补 0。
2. **整行删除不报数**：去重只删重复主键，行数守恒由 `runtime.checks.n_accounting` 断言。
3. **异常值直接进均值**：主分析保留，同时给 Tukey 围栏下的敏感性结果（`assumptions` 与报告第 4 节）。
4. **三组塞进 t 检验**：分组水平 ≥3 时只能走 ANOVA/KW，事后用 Holm。
5. **只报 p 值**：每个比较强制带效应量与区间；秩检验确实没有稳定解析 CI 时明示“CI 不可得”，不编造。
6. **p=0.04 写成“证明有效”**：解释模板固定为“差异有统计学意义”，另附区间与“相关不等于因果”的不确定性条目。
7. **单位不明仍混算**：同列出现多种单位时只记录不换算（N-02），进 `pending_human`。
8. **换台机器跑不出同一数字**：无随机性来源，唯一的 bootstrap 用固定种子；浮点输出统一 `%.12g`。
9. **把日期当数值**：`2026-01-05` 这类列若按数字解析，会得到“均值 2026 年”并生成无意义的组间比较（本包开发期实测出现过一条 `decision=insufficient` 的伪检验）。现按 `YYYY-MM-DD` / `YYYY/MM/DD` 形态判为非数值，只作分类描述，不进推断与相关。

## 7. 适用边界

- 适用：单表、行独立或近似独立、目标为两组/多组差异或变量间关联的常见科研表；样本量 3～数万行。
- 不适用：重复测量/配对结构（当前未做配对检验）、生存分析、混合效应模型、时间序列、加权抽样设计、多重插补。
- 上述情形会在 `pending_human`/`uncertainty` 中提示，而不是给出看似正确的错误检验。
