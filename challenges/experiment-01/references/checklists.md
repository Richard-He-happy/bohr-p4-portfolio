# 复用清单：对照设置 / 参数表 / 自检 / 质量锚点

配套 `experiment-plan-builder` 使用。三块内容都可独立复制到别的方案里用，不依赖本 Skill 的代码。

## 1. 对照设置检查清单

逐项确认。每个对照都要写明它排除哪一种混杂，写不出"排除什么"的对照就是凑数。

| 对照 | 作用 | 排除的混杂 | 缺失后果 |
|---|---|---|---|
| 空白（blank） | 只有培养基/溶剂/底物，无样本无药 | 试剂与器皿的本底信号 | 信号无法归因，读数偏高被误判为效应 |
| 阴性（negative） | 有样本、有载体、无活性处理 | 载体/操作本身引起的效应 | 把操作效应当成处理效应 |
| 阳性（positive） | 已知必然产生效应的参照 | 体系灵敏度、批间失效、操作失误 | 出现全阴性时无法区分"药无效"与"体系坏了" |
| 溶剂/载体（vehicle） | 与给药组等体积溶剂 | 溶剂本身的毒性或干扰 | 剂量效应被溶剂效应污染 |
| 未处理（untreated） | 完全不动 | 时间、培养、离位造成的漂移 | 长期实验中把漂移当效应 |
| 批内/位点（plate/position） | 同一处理多点位或随机化布板 | 孔板边缘效应、位置梯度 | 系统性偏倚伪装成生物学差异 |
| 技术重复 | 同一样本多次测量 | 测量误差 | 无法区分测量噪声与真实差异 |

最低要求：**处理组 + 空白 + 阴性 + 阳性** 四类齐全；凡使用溶剂，必须另设载体对照。
重复：生物学重复 ≥3；技术重复不替代生物学重复（技术重复只压测量误差）。

## 2. 参数表模板

复制为 CSV 或 Markdown 表。`basis` 一列必须写出依据来源（`case.json#/equipment/0`、`principle`、`missing`），空着即视为缺口。

| 步骤 | 参数 | 目标值 | 允许范围/单位 | 依据来源 | 越界处置 |
|---|---|---|---|---|---|
| S1 | 温度 | 37 °C | 设备 0–60 °C；允许域 {4, 25, 37} | `case.json#/equipment/1.range` | 裁剪至最近允许值并记变更 |
| S1 | 波长 | 450 nm | 设备支持范围 | `case.json#/equipment/0` | 无法裁剪则保留硬约束 |
| S2 | 孵育时长 | 24 h | 输入给定 | `case.json#/candidate_plans/0` | 无时长则标下界 |
| S3 | 重复数 n | 3 | ≥3（统计下界） | principle | 低于 3 需专家确认 |
| S3 | 单孔体积 | 100 µL | 板型规格 | missing（示例） | 列缺口，不猜 |

规则：目标值必须落在「设备量程 ∩ 输入允许域」内；两者冲突时取交集并记录被裁剪的一侧。

## 3. 提交前自检清单

- [ ] 假设写成可检验形式，含零假设与判定阈值；阈值有来源或明标 `missing`
- [ ] 自变量有操作定义（怎么设水平），因变量有测量方式（什么仪器、什么单位）
- [ ] 至少四类对照齐全，每类写明排除的混杂
- [ ] n 有来源：输入给定 / 由效应量与离散度推算 / 统计下界；三者都不是则标缺口
- [ ] 每个参数都有范围与单位，且与设备量程相容
- [ ] 成本 = 材料（用量 × 单价，单位已换算）+ 机时（用时 × 费率），合计与分项能对上
- [ ] 墙钟时间按阶段串联计算，未并行化的步骤不合并
- [ ] 时间窗与预算各自有"是否满足"的明确结论；不满足时给出具体数值差
- [ ] 风险表逐项含：早期信号、处置、停止条件、替代路径、责任人
- [ ] 停止条件可操作（例如"阳性对照信号低于本底 2 倍即停"），不是"视情况而定"
- [ ] 安全、伦理、设备排期确认单列为待确认事项，未写成已确认
- [ ] 每条关键设计选择能指回输入的 locator + quote，或明确标为原则/缺口
- [ ] 方案版本号、生成时间、输入哈希齐全，他人可复跑比对
- [ ] 缺口单独列出，与"已确定"内容分开呈现

## 4. 质量锚点（自评用）

用于判断一份方案处于哪一档，不是平台评分细则。

| 档位 | 特征 |
|---|---|
| 不可用 | 复述研究目标；只有通用流程；无对照或仅空白；参数无范围；无成本与排期 |
| 勉强可用 | 六类要素都在，但参数无来源、对照未说明排除什么、成本粗略、风险只写"注意安全" |
| 可用 | 假设可检验、四类对照齐全、参数在量程内、成本与墙钟可核算、风险含处置与停止条件 |
| 可复核 | 在"可用"之上，每条关键选择有 locator + quote，版本与运行记录齐全，缺口与不确定项分列 |
| 可移交 | 在"可复核"之上，他人不追问即可直接排期执行；冲突与依赖失配已有预案 |

## 5. 缺口话术

| 缺口 | 写法 |
|---|---|
| 无设备量程 | 「设备 X 未给量程，参数 Y 暂按输入给定值，需确认后可裁剪」（列待确认） |
| 无预算 | 「已核算成本 Z，预算上限未给，无法判定是否超支」 |
| 无时间窗 | 「墙钟预计 W，时间窗未给，无法判定是否可排期」 |
| 无单价 | 「试剂 R 无单价，该行未计入合计」 |
| 单位不可换算 | 「试剂 R 用量单位与计价单位不一致，未计入合计」 |
| 规格缺失 | 「试剂 R 规格未给，纯度/浓度待确认，相关参数按原则值而非输入值」 |

## 6. 维护

本文件是纯文本知识，不含代码；新增实验体系时补充第 1 节对照与第 2 节参数行即可。
改动不影响 `scripts/` 运行结果，但请同步检查 `SKILL.md` 第 14 节清单是否仍与文件一致。
