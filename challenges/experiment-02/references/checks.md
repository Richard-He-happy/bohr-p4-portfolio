# 检查项库 v1.0.0（feasibility check library）

本文件是 `scripts/feas.py` 的唯一检查项来源：脚本启动时解析下方 `checks` 代码块，不重复定义。
改动检查项只需改本文件并递增版本号；`id` 语义不得复用。

## 1. 表格格式

每行 8 列，` | ` 分隔：

```
id | 类别 | 检查项 | 依据号 | severity | needs_human | 探针组 | 缺失时动作
```

- **探针组**：`@@` 分隔多组，组内 `;` 分隔候选字面量（脚本按字面量转义匹配，非正则）。多组之间是"且"：全部命中才算 `met`，任一组缺失即 `gap`。留 `-` 表示该检查为**算术派生**（由脚本计算，不走探针）。
- **缺失时动作**：方案缺失该项时输出的可执行条件，直接进入 `conditions` 与 `pending_human`。

## 2. 依据编号的含义

| 依据号 | 判定依据来源 | 可复核方式 |
|-|-|-|
| `R-H*` `R-C*` `R-K*` | 本 Skill 的方法学规则（可证伪性、对照可分离性、失效模式预案的结构要求） | 见 §3 规则原文；判据只看方案文本是否具备要素 |
| `R-R*` `R-T*` `R-P*` | **输入侧契约**：设备量程/精度/货期/价格、试剂库存/规格、预算与时间窗 | 算术过程写入 `arithmetic`，`inputs` 全为输入原值，可复算 |
| `R-E*` | 伦理与安全合规触发规则（人体/动物/危化/个人数据）+ 方案自述的审批状态 | 触发词命中即要求对应审批；审批周期只用输入给出的数字，未给则转人工 |

> 本 Skill 不内置任何"行业常识数值"（如审批通常几周、某设备典型精度）。凡是输入未给的数字，一律不参与算术，写入 `uncertainty` 与 `pending_human`。

## 3. 规则原文（R-H / R-C / R-K）

- **R-H1 可检验假设**：方案须同时给出①研究/比较对象 ②比较方向（更高/更低/优于/差异）。只有目标陈述（"研究 X 的影响"）不算假设。
- **R-H2 变量定义**：自变量与因变量必须显式命名，不能只出现在步骤里。
- **R-H3 因变量可测量**：因变量须对应具体读出量（仪器读数/计数/浓度/成像指标），只写"评估效果"不算。
- **R-H4 判读标准**：须有把测量值转成结论的规则（阈值、阳性判定、接受区间）。
- **R-H5 混杂**：须识别至少一个可能混杂来源（批次、基线、操作者、时间）并说明处理。
- **R-C1/C2**：阴性（空白/溶剂/未处理）与阳性（标准品/参考品/校准）对照缺一不可；只有空白对照不足以证明方法有效。
- **R-C3**：重复须写清 `n` 及重复类型（生物学重复 vs 技术重复），二者不可互相替代。
- **R-C4**：每个处理组须有对应同级对照，且一次只改变一个因素；否则效应不可归因。
- **R-C5**：随机化/盲法/区组用于排除操作者与批次偏倚。
- **R-K1…K5**：每类失效必须有 **触发器（怎么发现）+ 处置（做什么）+ 影响面（哪些数据作废）**；只写"如失败则重复"不算预案。
- **R-K6**：须有停止/中止判据与转人工节点（什么情况下不再继续投入）。

## 4. 探针匹配与判定口径

- 匹配在规范化文本上进行：NFKC、`μ/µ→u`、`℃→°c`、`×g→rcf`、破折号统一为 `-`。
- `met` = 全部探针组命中；`gap` = 任一组未命中（**方案没写就是缺失，不因"通常会做"记通过**）。
- `partial` = 部分要素具备（仅用于算术派生项，如部分设备状态已知）。
- `blocked` = 输入数字证明硬冲突（参数超出全部可用设备能力、总历时超时间窗、费用超预算）。
- `na` = 该检查不适用（如不涉及人体样本时的 E-01），不计入覆盖率分母。
- `needs_human=1` 的项即使 `met`，也只代表"方案里有相应表述"，不代表审批已获批准。

## 6. 派生检查的算术口径

| 检查 | 计算 | 说明 |
|-|-|-|
| R-02 / P-02 | 参数基值 vs 同量纲设备量程并集 `[min lo, max hi]` | 超出并集判 `blocked`，差值写入 `arithmetic` |
| R-03 | 方案同句用量 vs 库存（同量纲换算） | 库存缺失记 `gap`，不假定有货 |
| R-04 | `max(货期, 预约周期)` vs 时间窗 | 只用输入给出的天数 |
| R-05/T-02/T-03/T-04 | 见 `references/schema.md` §5 公式表 | 全部 `inputs` 可复算 |
| C-03 | `n/组 = 2(z₁₋α/₂+z₁₋β)²σ²/Δ²` | 仅在输入同时给出 σ 与 Δ 时计算 |
| E-05 | 审批状态 + 周期 vs 时间窗 | 状态未知一律 `pending_human` |
