# 文献翻译规则（执行口径）

本文件是翻译与校验的**判据**。脚本只做机械可判的部分；语义判断由执行 Skill 的 Agent 在译文里落实，并在 `result.json` 中如实标注。

## 1. 术语：先锁定，再全篇回填

1. `prepare` 生成 `work/glossary.csv`（`term,translation,category,expansion,freq,first_seg,first_page,status`）。
2. 在 `translation` 列填译名 → 该行变为 `locked`（脚本以“非空即锁定”判定，不依赖状态字）。
3. 锁定后，**原文出现该术语的每一段，译文都必须出现同一译名**（忽略空白与连字符差异）。违反计入 `glossary.consistency.violations`，并写入该段的 `gviol`。
4. 译名细则（Agent 执行）：
   - 缩写：首次出现给“中文全称（缩写）”，其后统一用缩写或全称，二选一，全篇一致。
   - 学科惯用译名优先（如 siRNA→小干扰RNA、knockout→敲除），不要为文采换词。
   - 同一英文词在不同语义下可分化（如 `expression` 在“基因表达/表达量”中区分），但须在术语表里显式登记两个附录行（`term` 加限定后缀，如 `expression (gene)`），不得悄悄改写。
   - 术语表不覆盖的专名（基因、蛋白、细胞系、试剂）保留原文大小写与上下标，如 `SREBP2`、`IL-6`。
5. 判定口径：只检查“原文出现 → 译文含译名”，不检查语序与格；因此漏译、改写导致的缺译名会被抓出，译文合理省略（如代词化）会误报，故 `consistency.rate` 作为质量指标而非否决条件。

## 2. 受保护标记：逐字保留，不改写

| 类别 | 例 | 处理 |
|-|-|-|
| 文献标记 | `[12]`、`[13,14]`、`(Smith et al., 2020)` | 原样保留，含括号与逗号 |
| 图表/公式编号 | `Fig. 2A`、`Table 1`、`Eq. (4)`、`Supplementary Fig. 3` | 原样保留（推荐保留英文编号形式） |
| 公式 | `$...$`、`\(...\)`、`k_{cat}`、`E = mc^2` | 原样保留，不译、不改符号 |
| 数字 | `3.4`、`80%`、`p < 0.05`、`24` | 原样保留；中文句内不补“约”等模糊词 |
| 单位 | `mg/kg`、`mmol/L`、`µL`、`°C`、`rpm` | 原样保留大小写与斜杠 |

校验：`check_seg()` 从原文抽出上述标记（先剔公式，再剔引用与图表编号，最后取数字与单位），在译文中做“去空白 + 统一连字符”后的逐字包含判断；缺失项进该段 `missing`，聚合到 `token_fidelity`。`C4_tokens` 以 0.9 为通过线。

## 3. 关系：指代、否定、限定、因果

- 否定：`not / no / never / without / fail / lack / 未 / 不 / 无` 必须显式译出；双重否定不得简化为否定。
- 限定：`only`, `at least`, `up to`, `in part`, `except`, `unless`, `whereas`, `although` 的**范围与让步关系**必须保留；不要把 `although` 译成因果，不要把 `was not altered` 译成“有所改变”。
- 时态与情态：`may/might/suggest` 译作“可能/提示”，不得升级为“证明”。
- 数字口径：`~`, `approximately`, `up to`, `<` 与 `≤` 不得互换。
- 脚本对否定做启发式计数比对（原文有否定线索而译文无 → `negation_dropped`），只作为人工复核线索（可能误报），写入 `pending_human`。

## 4. 段落与对齐

- 段号 `P###` 由脚本分配，**不得重排、不得合并**；译文键名必须与段号严格一致。
- 一段一译：不把两段合成一段，不把一段拆成多段（可在段内分句）。
- 跨页/跨栏：`segment()` 以空行、标题、题注、公式、参考文献为边界，页内软换行合并（行尾连字符且下行小写时去连字符），因此跨页段落会落在一个段号内；若原文在页脚被截断，按语义判断是否接续，并在 `pending_human` 说明。
- 标题：译为中文标题，保留编号（`2. Results` → `2. 结果`）。
- 图表题注：整段翻译，题注内的编号与括号内容按第 2 节保留。
- 公式段（`kind=equation`）：可只保留原式 + 编号，必要时补一句中文说明，且必须保留全部符号。
- 参考文献（`kind=reference`）：**不翻译**，逐字保留；计入 `references_preserved`，不计入覆盖率分母。

## 5. 未译与不确定：显式标注，不含混

- 无法确定含义时，译文中用 `【待确认:原文词】` 标注，并把该段写入 `pending_human`（原因 + 建议动作）。
- 整段不译时，`translations` 中不要给该段键值；脚本会写 `untranslated` 并在双语稿中标 `【未译 untranslated】`。**禁止**用摘要、意译或“（略）”填充。
- 原文残缺/乱码：不要补写；在 `uncertainty` 记录影响范围（`U1` 文字层、`U2` 无译文输入）。

## 6. 语言与文体

- 默认译入简体中文；案例要求英文时由 `task`/`case` 判定（脚本识别 `into English`、`译为英文` 等信号后置 `target_language=en`）。
- 学术文体：陈述句为主，避免口语与文学化修饰；术语不意译成比喻。
- 数字与单位之间保留原空格习惯；中文句内标点用全角，公式与代码用半角。
- 不添加原文没有的引用、数值、结论、限定词；不删除原文的限定与否定。

## 7. 质量判据（与 rubric 对齐）

| 判据 | 机器可判 | 字段 |
|-|-|-|
| 术语稳 | 锁定术语在译文中的出现率 | `glossary.consistency.rate`、`C5_glossary` |
| 段落全 | 覆盖率、重复段号 | `translation.coverage`、`C3_coverage` |
| 关系准 | 标记逐字保留率 + 否定线索 | `translation.token_fidelity`、`flags` |
| 可核验 | 每段 `seg_id/page/kind/section` + claim 的 `quote/location` | `paragraphs`、`claims`、`C2_anchor`、`C6_claims` |

上述指标只覆盖**可机检**部分；译文的语义准确性、语体与可读性仍需人工或评审判断，结果文件不声称已自动判定“翻译质量合格”。
