# 审查判定手册（review-fact-check）

本文件是"怎么判"的部分：判定口径、支持程度定义、严重度分级、证据标准、误报控制与逐节清单。规则本体在 `checks.json`，字段格式在 `io_contract.md`。

## 1. 三条底线

1. **引用存在 ≠ 引用支持结论。** 必须分开记录：条目是否存在（结构问题），结论是否被支持（语义问题）。
2. **没有定位就没有结论。** 每条 issue 必须能在原文按 `locator` 找到，且 `quote` 逐字可回查；脚本会逐条校验，不通过的自动进 `pending_human`。
3. **判断不了就说判断不了。** 外部文献正文、出版状态、数据库权限不在输入内时，只能挂起，不能凭标题、期刊名或年份推测。

## 2. 引用支持判定（四档）

| 档位 | 判据 | 典型处置 |
|---|---|---|
| `full` | 被引文献的结论/数据直接覆盖该句范围，对象、条件、量级一致 | 无需修改 |
| `partial` | 方向一致但范围被扩大（如从亚组推到总体、从相关推到因果、从体外推到临床） | 收窄表述或补引更强的原始证据；`major` 或 `minor` 视结论地位 |
| `none` | 被引文献主题相关但结论不涉及该断言，或结论相反 | 换引或删除该断言；`major` |
| `undetermined` | 输入未提供被引文献正文/数据；或引文歧义无法定位到唯一条目 | `pending_human`，写明"需要哪篇文献的哪一节/哪张表" |

判定时必须记录三类证据：句子的 `claim_quote` + 被引条目（作者/年份/标题/DOI）+ 判定理由（比较了什么）。**不得**用"该文献很有名"或摘要措辞替代比较。

**常见过度推断模式**（命中即重点看）：
- 综述/荟萃分析 → 具体因果或机制断言；
- 动物/细胞模型 → 人群建议或临床结论；
- 横断面/相关性分析 → "导致/改善/提高"；
- 单一剂量/单一人群 → "普遍/所有/最佳"；
- 预印本 → "已被证实"。

## 3. 事实与数值核验

按可判定性排序，优先报"算术可判定"的问题：

1. **百分比与分数**：`a/b` 与标注百分比偏差 > max(0.6, 2%) 即判 `confirmed`（脚本自动算）。
2. **样本量**：摘要 `N=` 与正文/表 1 `N=` 无交集 → `major`，但标 `needs_human`（可能摘要指亚组）。
3. **计数守恒**：亚组人数之和 ≠ 总数；流程图数字与正文不一致（未给流程图时挂起）。
4. **单位与量纲**：同一指标混用 mg/mL、μM/mM、小时/天；图表轴单位与正文不一致。
5. **统计量**：`p=0.000` 不可能；`p<0.05` 与"显著"搭配需给出检验；`mean±SD` 与 `±SEM` 混用；缺 n。
6. **数值口径**：同一指标在正文、表、图注、摘要四处出现不同值时，报"不一致"并列出各处定位，交由作者确认；**不得**自行选择"正确值"。

## 4. 统计报告完整性

最低可接受集合：样本量依据（或明确声明探索性）、每组 n、检验方法、统计量+自由度、精确 p 值、效应量与 95% CI、缺失数据处理、多重比较校正。

缺项按影响定级：缺效应量/CI → `minor`；缺检验方法或只用"显著" → `minor`；`p=0.000`、以趋势代替检验、把 `p>0.05` 读成"无差异" → `major`。

## 5. 方法设计与论证链

- 有组间比较结论 → 方法中必须有对照/比较组、随机化与盲法（若声称）、样本来源与入排标准。
- 体外/细胞证据 → 结论不得延伸到患者疗效。
- 因果措辞（causes / leads to / improves）需干预或机制证据；仅有相关性数据时降级为 associated with 并说明混杂。
- 循环论证、以偏概全（单中心/单批次 → 普遍规律）、结论超出数据范围，按"结论地位"定 `major`/`minor`。
- 新颖性断言（first / unprecedented）必须附检索策略与时间范围，否则 `minor`。

## 6. 学术规范

| 项 | 缺失时的定级 | 说明 |
|---|---|---|
| 伦理审批/知情同意 | `major` + `needs_human` | 涉及人/动物时必须有；无要求须写明依据 |
| 利益冲突 | `minor` | 无则写"无" |
| 数据/代码可用性 | `minor` | 仓库链接、登记号或获取条件 |
| 资助 | `minor` | 含项目编号；无资助注明 |
| 作者贡献 | `minor` | 建议 CRediT |
| 报告指南 | `minor` | RCT→CONSORT，系统评价→PRISMA，观察性→STROBE，动物→ARRIVE |
| 撤稿/关注声明 | `major` + `pending_human` | 必须核验当前状态与版本 |
| 预印本引用 | `minor` + `pending_human` | 有正式版须改引 |
| 重复 DOI | `major` | 同一文献被当两项证据 |
| 重复发表/拆分发表线索 | `info` + `pending_human` | 需与既有发表比对 |

## 7. 严重度与 certainty 的搭配

| 情形 | severity | certainty |
|---|---|---|
| 算术/字符串可判定（百分比错、编号悬空、重复 DOI） | major/minor | `confirmed` |
| 规则+上下文可判定（缺对照、因果过度、显著无检验） | major/minor | `likely` |
| 需外部核验（撤稿、版本、被引文献内容、补充材料） | major/minor | `needs_human` |

`certainty=needs_human` 的条目必须同时出现在 `pending_human[]`，并写清"需要什么材料/哪一步操作"。

## 8. 误报控制（比多报更重要）

- 先查"反面证据"再报：文中有 `control/comparator`、`inclusion criteria`、`95% CI`、`consistent with` 时，不要报"缺失"。
- 章节作用域：方法类规则只在 methods/discussion 范围内判；结论类规则只看 conclusion/abstract。
- 术语歧义：`significant` 在统计外语境（"a significant advance"）不按 p 值规则报，改为 `info`。
- 引用密度：综述类文章正文引用密集，`uncited_assertion` 只报"明确的他人结论句"，不报背景铺垫。
- 数值一致：四舍五入导致的小差异（<2%）不计；只在四舍五入无法解释时报。
- 同一根因多处出现：合并为一条，`claim` 中列出其余定位，避免刷条目数。

## 9. 逐节检查清单

**摘要**：结论是否与结果一致；N、效应量、p 值是否与正文一致；有无未在正文出现的数字；是否出现"首次/显著改善"等未被结果支撑的措辞。

**引言**：每个"已有研究表明"是否带引用；引用是否支持该句；有无把综述当原始证据；研究缺口与本文目标是否对齐。

**方法**：设计类型与对照；随机化/盲法/分配隐藏；入排标准；样本量依据；终点定义与预设分析；统计方法与多重比较；伦理与注册号；试剂/仪器型号与版本。

**结果**：与方法的分析集是否一致；n 与流程图；统计量与 p 的报告完整度；图注与正文数值；阴性结果是否被淡化；亚组是否预设。

**讨论/结论**：是否重复结果而非新增结论；是否回应与预期不符的结果；局限性是否覆盖主要威胁；因果措辞是否与设计匹配；临床/政策建议是否超出数据。

**参考文献**：编号连续、条目齐全、DOI/年份/期刊可核；重复与自引比例；撤稿/预印本/更正状态。

## 10. 第二遍语义审查的提示模板

对 `citation_pairs.json` 中每一组（`claim_quote` + `citation` + `ref_raw`）：

1. 先判断该句的**断言类型**：描述性 / 关联性 / 因果性 / 方法学 / 数量陈述。
2. 找被引文献中的对应证据（输入若含该文献全文或摘要，定位到节/表/页；否则 `undetermined`）。
3. 比较四件事：对象、条件（剂量/时程/人群）、方向、量级。
4. 给出 `verdict` + 一句理由 + 证据位置；写入 `citation_verdicts`。
5. 若 `verdict` 为 `partial`/`none`，追加一条 `findings`（含逐字 `quote`、`severity`、`suggested_fix`）。

## 11. 交付话术

报告开头一句话说明审查范围与最大风险；结论部分按"阻断问题—建议问题—待复核"顺序；不要用"整体质量较好但……"替代逐条证据。每条建议写成可执行动作（改成什么、补哪一节、换哪类证据），不写"建议进一步完善"。
